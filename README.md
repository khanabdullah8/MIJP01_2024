# Visual Cryptography Technique

## Project Overview
This project implements Visual Cryptography for secure message sharing using Java, JSP, Servlets, and MySQL.

## Features
- User Registration and Login
- Message Encryption
- Secret Image Generation
- Secure Message Sharing
- Admin Panel
- User Management

## Technologies Used
- Java
- JSP
- Servlets
- MySQL
- Apache Tomcat
- HTML/CSS/JavaScript
